Restoran printerlarini ulash

  1. Printer ulangan kompyuterga Node.js o‘rnating. Bu kompyuter ishlayotgan paytda cheklar chiqadi.
  2. Admin → Sozlamalar’da printer qo‘shing. IP printer uchun mahalliy IP va portni (odatda 9100) kiriting. USB uchun “Windows printeri”ni tanlab, Windows’dagi printer nomini aynan kiriting. Windows drayverini avval o‘rnating.
  3. Menyu kategoriyalarini mos printerga belgilang: masalan Kaboblar → Kabobxona, Baliqlar → Baliqxona. Qog‘oz enini tanlang. IP rejimi ESC/POS bilan mos printerlar uchun; boshqa modellarni Windows drayveri orqali ulang.
  4. Ulash dasturini yuklab oling va alohida papkaga joylashtiring.
  5. Admin → Sozlamalar → Printer kompyuterini ulash bo‘limida kalit yarating. Kalitni boshqa odamlarga bermang.
  6. Shu papkada PowerShell ochib quyidagilarni bajaring:
$env:PRINT_SERVER_URL = 'https://choyxonaazizxon.onrender.com'
$env:PRINT_AGENT_TOKEN = 'ADMIN_YARATGAN_KALIT'
node .\print-agent.cjs

Bir restoran uchun ulash dasturining bitta nusxasini ishlating. Barcha sozlamalar admin panelidan olinadi. IP printer shu kompyuterdan tarmoq orqali ko‘rinishi kerak. Windows rejimida qog‘oz va drayver sozlamalarini Windows’dan ham tanlang.

Admin panelidagi “Cheklar navbati”dan holatni kuzating. “Yuborildi” holati qurilma yoki Windows navbatiga topshirilganini bildiradi, qog‘oz chiqqanini printerda tekshiring. Kompyuter o‘chib qolsa, uzilgan ishlar avtomatik qayta chop etilmaydi: avval qog‘ozni tekshirib, keyin admin panelidan qayta yuboring.
